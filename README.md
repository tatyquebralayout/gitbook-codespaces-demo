# GitBook Codespaces Demo

**Um livro técnico que abre e roda inteiro no navegador, sem instalar nada no seu computador.**
*A technical book that opens and runs entirely in the browser, with nothing to install on your computer.*

Este repositório é um modelo pra quem quer ensinar com material escrito e prática no mesmo lugar. Ele junta um livro em GitBook e um laboratório em Python, e roda num GitHub Codespace já configurado com Python 3.11.

## O que tem aqui

| Parte | Arquivo | O que é |
|---|---|---|
| Introdução | `README.md` | Esta página |
| Tutorial | `tutorial/01-getting-started.md` | Como abrir o livro no Codespace |
| Laboratório | `lab/analyze.py` | Um script curto que calcula a média e a maior nota de uma pequena tabela |
| Índice | `SUMMARY.md` | A ordem dos capítulos do livro |

## Como usar

1. Clique em **Code → Codespaces → Create codespace** neste repositório.
2. No terminal, rode o laboratório com `python lab/analyze.py`.
3. Pra ver o livro, siga o [tutorial](tutorial/01-getting-started.md).

---

**In English:** a template for teaching with written material and hands-on practice in one place. It combines a GitBook book with a small Python lab and runs in a GitHub Codespace preconfigured with Python 3.11. Open a Codespace, run `python lab/analyze.py`, and follow the tutorial to preview the book.
